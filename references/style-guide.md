# 领英学习风格视觉规范

B-Roll 要像 LinkedIn Learning 的课程画面：干净、明亮、信息清楚，品牌色克制，动效轻快但不花哨。下面的数值都来自已经交付、用户认可过的成品；新画面照着用，模板 `templates/broll.html` 里已经写好了。

## 画布与安全区

- 1920×1080，DPR 1；要 4K 就渲染时加 `--scale 2`，布局不用改。
- **下方 200 像素（y > 880）留给字幕，内容不进这个区域。** 浏览器打开时加 `&guides` 会显示橙色斜纹提示区。
- 标题区：顶部 84–92px 起，高 84px。主体内容放在 y 180–860。

## 颜色

| 用途 | 变量 | 值 |
|---|---|---|
| 背景（暖灰） | `--bg` | #F3F2EF |
| 卡片 | `--card` | #FFFFFF |
| 正文 / 次要 / 更淡 | `--ink` `--muted` `--faint` | #191919 / #666666 / #A8A6A2 |
| 分隔线 / 浅灰块 | `--line` `--gray` | #E3E0DB / #EDEBE7 |
| 品牌蓝（主强调） | `--blue` | #0A66C2 |
| 深蓝 / 中蓝 / 浅蓝 | `--blue-dark` `--blue-mid` `--blue-light` | #004182 / #378FE9 / #70B5F9 |
| 蓝色底 | `--tint` `--tint2` | #EAF3FC / #D3E5F8 |
| 提醒、注意（琥珀） | `--amber` `--amber-ink` `--amber-tint` | #E7A33E / #915907 / #FDF1DC |
| 正向、完成（绿） | `--green` `--green-tint` | #057642 / #E3F2E9 |

一屏只有一个主强调色（蓝）。琥珀只用于「注意 / 代价 / 限制」，绿只用于「对 / 完成 / 推荐」。不用红色报警，不用渐变大色块铺底。

## 字体与文字

- `"PingFang SC","Hiragino Sans GB","Helvetica Neue",Arial,sans-serif`，开 `-webkit-font-smoothing:antialiased`。
- 数字用 `font-variant-numeric:tabular-nums`（`.tnum`），数字变化时不抖。
- 标题 58px / 600；卡片主字 40–48px / 700；说明 26–30px，`--muted`。
- 标题里要强调的词用 `<em>`，显示为蓝色，不加粗不斜体。
- **标题上方不加小字眉题**（eyebrow，例如「领英学习 · 课程介绍」）——用户明确要求去掉。
- 文字要短：标题一句话、卡片 2–6 个字的主词 + 一行说明。口播里的长句只取关键词。
- 用简体中文；软件界面名称照原样（「工作空间」「专家」「Skill」）。

## 组件

- **卡片**：白底，圆角 24–28，阴影 `0 1px 3px rgba(0,0,0,.06), 0 10px 30px rgba(0,0,0,.06)`。
- **叠在录屏上的卡片**（`.card.glass`、`.pnl`、`.tc`）：`rgba(255,255,255,.94–.95)`，阴影加重为 `0 14px 40px rgba(0,0,0,.28)`，否则在亮色录屏上会糊在一起。
- **胶囊**（`.pill.amber/.green/.blue`）：高 52–56，圆角一半，图标 + 一句话，用来点出提醒或结论。
- **图标**：24 视框的描边图标，`stroke-width:2`，圆头圆角（模板 `IC` 里有常用的，缺了就照这个规格画）。
- **真实软件图标**：画面里提到具体软件（Excel、Word、微信、WorkBuddy……）一律用真图标，`scripts/app_icon.sh` 从 /Applications 里提取；做 WorkBuddy 内容时用官方 logo。不要用字母方块或 emoji 代替。
- **背景**：纯色米白 `--bg` #F3F2EF（想要纯白就改成 #FFFFFF），**不用任何渐变**——不加光晕、渐变底、渐变条、渐变图标底。装饰只留角落一块浅蓝点阵（`.dotgrid`），不抢内容。
- **配图底色**：Canva 生成的插图也要纯白 / 米白底、无渐变；生成出来底色偏黄就用 ffmpeg `colorkey` 换成白底（见 canva.md）。
- **连接线 / 流程线**：浅蓝 #70B5F9，4px，虚线 `2 12` 或实线，用 `draw()` 逐渐画出。

## 增强式（叠在原画面上）的标注词汇

- **压暗 + 挖洞**：`.dim`，`box-shadow:0 0 0 3000px rgba(18,24,33,.62)`，洞就是要看的区域。
- **聚光框**：`.spot`，4px 蓝边 + `0 0 0 8px rgba(10,102,194,.25)` 外晕。
- **单元格 / 行框**：`.box`，3px 蓝或琥珀边 + 10% 底色。
- **编号**：`.num`，48px 圆，和说明卡里的编号一一对应。
- **箭头**：SVG 路径 + marker 箭头，浅蓝 5px，从说明卡指向目标。
- **说明卡**：放在画面的空白处，不挡住正在讲的界面元素。
- 坐标从参考帧上量（`grab_frames.sh` 截图后用看图工具量），写在 HTML 场景注释里：「坐标量自 0:26 画面」。录屏有平移、滚动时，分段写坐标或改用遮盖式。

## 动效

- 每个画面都是时间 t 的纯函数（`renderAt(t)`），不用 CSS transition / animation，保证逐帧渲染确定。
- 常用：`enter`（上浮 20px 淡入）、`pop`（回弹放大，E.back c1=1.5）、`slide`（侧滑入出）、`titles`（标题交替：新的上浮 18px、旧的上移 12px）、`draw`（描线）、`bump`（高亮脉冲）。
- 时长：入场 0.4–0.6 秒，强调脉冲 0.6–0.9 秒，元素依次出现间隔 0.2–0.35 秒。
- **每个节拍对齐口播的字**：说到「快速」时「快速」那张卡亮。时间用 `word_times.py` 取，在 JS 注释里写「词 时间」。
- **开场不能空**：第一秒就要有主体在入场，不要先放一个空背景再慢慢出东西；画面信息要丰富（用户 2026-10-16 要求）。
- 遮盖式首尾：和真实画面交叉淡化 0.5 秒（有 `--src` 时自动，没有时用首尾参考帧 `.edge-in/.edge-out`）。
- 推镜头（Z）首尾必须回到原样（p=0），这样可以无缝接回原视频。
